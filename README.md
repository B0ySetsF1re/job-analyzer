# Job Posting Analyzer

Turns unstructured job postings into structured, typed data, stores them in Postgres,
and lets you compare postings against your CV and ask natural-language questions over them.

The LLM converts messy text into validated Pydantic models; everything after that is
ordinary code and SQL.

> Status: early development (Phase 1 — core pipeline).

## Stack

- **Backend:** Python 3.13, uv, FastAPI, Pydantic v2, PydanticAI, SQLAlchemy 2.0 (async),
  Alembic, Postgres, Procrastinate, OpenTelemetry
- **Frontend (optional):** React + Vite + TypeScript, client generated from OpenAPI
- **Infra:** Docker Compose (local), Helm + Kubernetes, Terraform (AWS: EKS, ECR, S3 + CloudFront)

## Architecture

```
POST /postings ──► Postgres (status: pending) ──► Procrastinate job
                                                       │
                                                       ▼
                                         Worker: PydanticAI extraction agent
                                                       │
                                                       ▼
                                   Postgres (PostingExtraction, status: processed/failed)
```

## Getting started

### Prerequisites

- [mise](https://mise.jdx.dev/) (recommended): installs the pinned Python / Node / uv versions.
  Not required — see [Without mise](#without-mise)
- Docker or Podman (for Postgres)

### Setup

All commands run from the repo root; `make` with no target lists every shortcut.

```bash
make install            # mise install + uv sync + create .env from .env.example
```

Or step by step: `mise install`, then `cd backend && uv sync`, then `cp .env.example .env`.
Configuration lives in `.env` (see `.env.example` for all variables).

#### Without mise

Only [uv](https://docs.astral.sh/uv/getting-started/installation/) and Docker are required;
uv downloads Python 3.13 itself if it's not installed.

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh   # or: brew install uv
make install                                      # skips mise, runs uv sync --python 3.13, creates .env
```

### Run the API

```bash
make db                 # Postgres in Docker (waits until healthy)
make migrate            # apply DB migrations
make dev                # API on the host with hot reload
```

Without make: `docker compose up -d`, then `cd backend && uv run uvicorn app.main:app --reload`.

| URL | What |
|---|---|
| http://localhost:8000 | API base URL |
| http://localhost:8000/health | Health check |
| http://localhost:8000/docs | Swagger UI (interactive, "Try it out") |
| http://localhost:8000/redoc | ReDoc (read-only reference) |
| http://localhost:8000/openapi.json | Raw OpenAPI 3.1 schema (source for the generated frontend client) |

Drop `--reload` when running under a debugger: the reloader spawns a child process,
so breakpoints won't hit.

### Test and lint

```bash
make check                          # lint + all tests
make test ARGS="-k health -v"       # pytest with extra args
make lint                           # ruff check + format check (no changes)
make fmt                            # auto-fix + format
```

Without make, from `backend/`: `uv run pytest`, `uv run ruff check .`, `uv run ruff format .`.

### Docker Compose

Default workflow: Postgres in Docker, API on the host (easier debugging). To run the API in a
container too:

```bash
make up                 # Postgres + API container (hot reload on backend/app)
make down               # stop everything (data kept in the `pgdata` volume)
docker compose down -v  # stop and wipe the database
```

Postgres: `localhost:5432`, user/pass/db `app`/`app`/`job_analyzer` (from `.env`).

## API

The OpenAPI schema is generated by FastAPI from the route definitions and Pydantic models,
so it always matches the code. Interactive docs: http://localhost:8000/docs (see
[Run the API](#run-the-api)).

| Method | Path | Description |
|---|---|---|
| GET | `/health` | Liveness check: `{"status": "ok", "env": "dev"}` |

_More endpoints are added per phase (postings, profile, match, ask)._
